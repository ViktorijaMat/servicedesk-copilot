# servicedesk-copilot

Idea:
A tool called ServiceDesk copilot, which should predict which team an incident should go to (escalation/routing), find 5 most similar past incidents and how they were solved and draft a reply based on those solutions.

Python version:
3.14.3

Libraries used:
datasets
pandas

Websites used:
https://huggingface.co/datasets/Tobi-Bueck/customer-support-tickets - for the "customer-support-tickets" dataset
https://medium.com/@prasanth32888/op-50-pandas-commands-you-should-know-136e62b8f9be - for pandas commands
